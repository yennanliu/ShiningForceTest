# Asset credits

Every file in `assets/` is listed here with its author and license (doc/05 §8, doc/04 §4).
No file is ripped, traced or extracted from another game.

| Files | What | Author | License |
| --- | --- | --- | --- |

| `textures/units/*.png` | Placeholder map sprite sheets (48×64 frames, 9 × 4), drawn by `tools/make_art.py` from doc/05 | Project Banner (generated) | Project-owned |
| `textures/icons/head_*.png` | Placeholder head icons (24×24): poison, sleep, advantage, bond, leader star, drawn by `tools/make_art.py` | Project Banner (generated) | Project-owned |
| `textures/battle/*.png` | Placeholder battle-scene poses (11 frames of 192×192 per unit), drawn by `tools/make_art.py` | Project Banner (generated) | Project-owned |
| `textures/backdrops/*.png` | Placeholder battle-scene backdrops (6 terrains, 1280×600), drawn by `tools/make_art.py` | Project Banner (generated) | Project-owned |
| `textures/tiles/*.png` | Placeholder 3D-map tile tops (32×32, 7 terrains), drawn by `tools/make_art.py` | Project Banner (generated) | Project-owned |
| `ui/*.png`, `ui/banner_theme.tres` | UI kit: Banner frame 9-slices, buttons, pennant (`tools/make_art.py`) and the theme (`tools/make_theme.gd`) | Project Banner (generated) | Project-owned |
